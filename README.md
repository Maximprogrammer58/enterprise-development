# AirlineApp - Лабораторная работа по РКП

## 🏗️ Архитектура проекта

### Уровни приложения

#### 1. AirlineApp.Domain - Доменный слой
- **Сущности бизнес-логики:** `AircraftFamily`, `AircraftModel`, `Flight`, `Passenger`, `Ticket`
- **Интерфейсы репозиториев** – абстракции для работы с данными
- Ядро приложения, содержащее бизнес-сущности и их поведение

#### 2. AirlineApp.Contracts - Слой контрактов
- **DTO (Data Transfer Objects):** отдельные модели для API
  - `EditDto` – для создания/обновления данных
  - `GetDto` – для чтения данных
- **Интерфейсы сервисов:** определяют контракты для CRUD операций
- Отделяет API и сервисы приложения от доменных сущностей

#### 3. AirlineApp.Infrastructure - Слой инфраструктуры
- **База данных:**
  - `AppDbContext` – конфигурация Entity Framework Core
  - Настроены связи между сущности, ограничения и индексы
  - Миграции для управления схемой БД
- **Репозитории:**
  - Реализация паттерна Repository для инкапсуляции доступа к данным
  - Каждый репозиторий отвечает за CRUD-операции для своей сущности
  - Абстрагирование от конкретной ORM через интерфейсы Domain слоя
- **RabbitMQ:**
  - `AirlineAppRabbitMqConsumer` - фоновый сервис для обработки сообщений из очереди
  - Интеграция с Aspire через `AddRabbitMq` для автоматической конфигурации
  - Обработка пакетов билетов с валидацией бизнес-правил

#### 4. AirlineApp.Application - Слой приложения
- **Сервисы:**
  - Содержат бизнес-логику приложения
  - Координируют работу между репозиториями и контроллерами
  - `TicketService.ReceiveContractList()` - обработка пакетов билетов из RabbitMQ с полной валидацией
- **Маппинг:**
  - AutoMapper для преобразования между сущностями и DTO
  - `AppMappingProfile` централизует все правила преобразования
- **Валидаторы:**
  - Используют FluentValidation для проверки входных данных
  - Проверяют обязательные поля, длины строк, бизнес-правила
  - Возвращают понятные сообщения об ошибках

#### 5. AirlineApp.API - Презентационный слой
- REST API контроллеры для всех сущностей
- Обработка HTTP запросов и маршрутизация
- Внедрение зависимостей через конструкторы
- **Интеграция с RabbitMQ:**
  - Фоновый сервис `AirlineAppRabbitMqConsumer` для непрерывной обработки сообщений
  - Валидация входящих контрактов на существование рейсов, пассажиров и уникальность мест
- **Централизованная обработка ошибок:**
  - Middleware для глобальной обработки исключений
  - Преобразование исключений в соответствующие HTTP статусы
  - Логирование ошибок для отладки
- **Типы обрабатываемых исключений:**
  - `KeyNotFoundException` → 404 Not Found
  - `ArgumentException` → 400 Bad Request
  - `InvalidOperationException` → 409 Conflict
  - `DbUpdateException` → 400 Bad Request
  - Общие исключения → 500 Internal Server Error

#### 6. AirlineApp.Generator - Генератор тестовых данных
- **Bogus для генерации реалистичных данных:**
  - `TicketGenerator` - создание тестовых билетов с русскоязычными данными
  - `TicketGeneratorExtensions.WithRecord()` - расширение для работы с Bogus и record типами
  - Генерация корректных данных, соответствующих бизнес-правилам
- **Поддержка всех сущностей:** рейсы, пассажиры, билеты с согласованными внешними ключами

#### 7. AirlineApp.Generator.RabbitMq.Host - Сервис генератора
- **Отдельное веб-приложение** для генерации и отправки данных
- **REST API эндпоинт:** `GET /api/generator` с параметрами:
  - `batchSize` - размер пакета сообщений
  - `payloadLimit` - общее количество сообщений
  - `waitTime` - задержка между пакетами
- **Интеграция с RabbitMQ:**
  - `TicketRabbitMqProducer` - отправка сгенерированных данных в очередь
  - `IProducerService` - абстракция для работы с брокером сообщений
- **Гибкая конфигурация** через параметры запроса

#### 8. AppHost - Оркестрация с Aspire
- Конфигурация инфраструктуры приложения
- MS SQL Server контейнер как основная БД
- **RabbitMQ контейнер** для асинхронной коммуникации
- Управление зависимостями между сервисами
- Упрощение разработки и развертывания
- **Мониторинг** через Aspire Dashboard

## 🛠️ Технологический стек

**Основные технологии:**
- .NET 8 - основная платформа разработки
- C# 12 - язык программирования
- Entity Framework Core 8 - ORM для работы с базой данных
- ASP.NET Core Web API - фреймворк для построения REST API
- MS SQL Server - система управления базами данных

**Вспомогательные библиотеки:**
- AutoMapper - объектно-объектное отображение
- FluentValidation - валидация входных данных
- xUnit - фреймворк для модульного тестирования
- Microsoft.EntityFrameworkCore - работа с Entity Framework Core
- Aspire.Hosting - оркестрация приложений
